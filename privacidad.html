Política de privacidad

Cuadre · Última actualización: 24 de noviembre de 2026

Cuadre es una aplicación de uso interno de un negocio de agente bancario en Perú. Esta política explica qué datos usa, para qué y cómo se protegen.

1. Datos de Google que usa la aplicación

Con la autorización del titular de la cuenta, Cuadre accede a una cuenta de Gmail del propio negocio con el permiso de solo lectura https://www.googleapis.com/auth/gmail.readonly.

Solo procesa los correos de notificación enviados por el BCP (notificacionesbcp.com.pe) y por Yape (yape.pe). Los demás correos se ignoran y no se guardan.

2. Para qué se usan

De cada notificación se extraen los datos de la operación (monto, fecha y hora, número de operación, tipo de operación y la contraparte que figura en el correo) para registrarla en el control de caja del negocio. No se usan para publicidad, perfiles ni ningún otro fin.

3. Dónde se guardan

Los datos se guardan en una computadora del negocio, en una base de datos local. El permiso de acceso a Gmail (token) se guarda cifrado. No se venden, no se comparten con terceros y no se transfieren fuera del negocio.

4. Uso limitado de los datos de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

5. Conservación y eliminación

Las operaciones registradas se conservan como parte de la contabilidad del negocio. El acceso a Gmail se puede revocar en cualquier momento desde la aplicación (Admin → Gmail → Desconectar) o desde myaccount.google.com/permissions. Al revocarlo, Cuadre deja de leer correos.

6. Contacto

Para cualquier consulta sobre esta política: cuadreactivacell@gmail.com.
